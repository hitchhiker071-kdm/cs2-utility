# 术语表（glossary）

| 术语 | 定义 |
|---|---|
| 道具本 | 本项目核心产物：按地图组织的 CS2 道具教学摘录集，每条含文字与动图 |
| 道具条目 | 单条摘录记录，字段见 ADR-0004（地图/点位/道具类型/投掷方式/瞄准点/效果/来源+时间戳/动图/备注） |
| 点位 | 道具的作用位置或投掷目标，命名法"位置 + 道具类型"，如"**A1 烟**"= 投向 A1 的烟雾弹 |
| 投掷方式 | 跳投 / 跑投 / 蹲投 等投掷手法 |
| 瞄准点 | 投掷时准星对准的参照物（建筑棱角、天空标记等），文字描述核心 |
| 来源视频 + 时间戳 | 教学出自哪个 B 站视频、几分几秒，用于溯源回看 |
| 动图 | 本项目中指 WebP/MP4 动画（非 GIF），用于直观展示投掷示范 |
| 流水线（MVP） | 一条完整链路：下载视频 → 截取片段 → 转码动图 → 录入数据 → 部署更新 |
| 静态托管 | 无需服务器的文件托管服务（GitHub Pages），打开网址即用 |
| 摘录 | 从教学视频中提取单条道具信息并入库的动作；摘录后源视频失效不影响条目 |
| yt-dlp | 开源免费视频下载工具，本项目中用于下载 B 站视频 |
| ffmpeg | 开源免费多媒体处理工具，本项目中用于截取、转码、压缩动图 |
| 战术条目 | 预留的条目类型，用于后续录入配合、套路等非单道具内容 |
| 非目标 | 明确不做的事：饰品库存/价格/行情、第三方 API 自动拉数据、多人协作/社区 |
