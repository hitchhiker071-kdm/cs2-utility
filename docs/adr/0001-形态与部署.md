# ADR-0001：形态与部署——本地静态网页 + GitHub Pages 公开

- 状态：已接受
- 日期：2026-07-29
- 背景：CS2 道具教学散落在大量 B 站视频中，每条教学往往只有十几秒，需要一套"道具本"把散落内容摘录成可快速查询的条目。

## 决策

1. 形态采用**本地静态网页应用**（HTML/CSS/JS + 数据文件），而非 Markdown/Obsidian、Excel、原生 App。
2. 部署采用 **GitHub Pages 公开部署**，手机/电脑打开网址即用。

## 备选方案

| 方案 | 被否原因 |
|---|---|
| Markdown + Obsidian | 零开发，但字段化结构、搜索、动图播放体验弱，手机端同步依赖笔记软件生态 |
| Excel | 动图无法内嵌展示，手机端体验差 |
| 原生桌面/移动 App | 开发成本高，跨设备分发麻烦，对"查一眼"场景过重 |
| 局域网访问 | 手机可用但电脑必须开机、出门不可用 |
| 私有托管（付费） | 无必要支出；公开对使用无影响 |

## 理由

- 使用场景是"赛前复习 + 游戏中忘了手机/电脑查一眼"，静态网页零安装、双端通用。
- 字段化数据结构 + 搜索 + 动图自动播放，网页是体验与成本的最佳平衡。
- GitHub Pages 免费、更新即上传，满足"手机随时看"。
- 公开的风险已评估：内容为 B 站公开教学片段、非商用、注明来源，版权投诉风险极低；最坏情况（仓库被下架）不影响本地文件，可随时重部署。

## 后果与代价

- 需要编写和维护前端代码（由 Reasonix 代劳）。
- 页面公开，**不得包含 Steam 账号、昵称等个人信息**。
- 内容录入依赖固定工作流（见 ADR-0003）。
