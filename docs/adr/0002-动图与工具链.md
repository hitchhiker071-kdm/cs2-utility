# ADR-0002：动图格式与本地工具链——WebP/MP4 + ffmpeg + yt-dlp

- 状态：已接受
- 日期：2026-07-29
- 背景：道具条目的核心信息是"站位 + 瞄准点 + 投掷动作"，需要动图直观展示；文字用于快速复习。

## 决策

1. 动图采用 **WebP/MP4 动画**（视情况选择），不用 GIF。浏览器自动播放效果一致，体积约为 GIF 的 1/10，几百条动图的存储与加载压力可接受。
2. 本地安装两个开源免费工具：
   - **ffmpeg**：视频截取、转码、压缩动图
   - **yt-dlp**：B 站视频下载

## 备选方案

| 方案 | 被否原因 |
|---|---|
| GIF | 体积大 10 倍，数百条目时代存储与加载不可接受 |
| 在线转换网站 | 依赖网络与第三方，批量效率低，素材隐私不可控 |
| 手工录屏 | 需自己会扔每个道具才能录出正确示范，成本远高于截取教学视频 |

## 理由

- 内容工作流是"从教学视频截片段"，下载 + 截取 + 转码是唯一合理链路。
- 用户已确认可接受安装工具。

## 后果与代价

- 动图截取后即成为本地文件，**源视频将来被删/失效不影响已摘录条目**——摘录越早越保值。
- 需维护动图体积规范（单条 ≤ 1~2MB 量级），保证手机加载流畅。
